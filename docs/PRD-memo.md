## 一、一句话目标

把 SnapNote 从「任务提醒便签」升级为「随身收集箱」：任何软件里复制的内容、
网页里右键的内容，随手收进备忘录，用多级分类管得井井有条，要用时一搜即得。

## 二、总体分期（已确认方案）

| 阶段 | 内容 | 体验 |
|------|------|------|
| **一期 v1.5.0** | 剪贴板捕获 + 备忘录管理界面 + 多级分类 + 敏感遮罩 | 任何软件里「复制即收集」，悬浮气泡一键归档 |
| **二期 v1.6.0** | 浏览器扩展（Chrome/Edge） | 网页里选中/图片真·右键「存入 SnapNote」，直接选分类 |

一期交付即可日常使用；二期把网页体验升级为你最初描述的「右键发送」。

## 三、一期详细设计

### 3.1 收集流（核心动线）

```
你在任意软件选中内容 → 复制（Ctrl+C / 右键→复制）
        ↓ （SnapNote 后台检测到剪贴板新内容）
右下角悬浮气泡：内容预览（文字 60 字 / 图片缩略）
  ├─ [归档] → 级联选分类（记住上次）→ 存入 + 确认提示
  └─ [忽略] / 8 秒无操作 → 自动消失，什么都不存
```

**防骚扰规则**（避免变成复制干扰器）：
- 同一内容近期捕获过 → 不再弹气泡（内容指纹去重）
- 少于 2 个字符的碎片（如复制单个数字）→ 不打扰
- 从 SnapNote 自己复制的文本（比如从备忘录再复制出来）→ 不弹
- **总开关**：托盘菜单 + 设置页随时关闭整个捕获
- 捕获开关默认**开启**（这是功能灵魂，嫌吵随时关）

**第二收集方式**（不弹气泡的快捷路径）：
- 快捷键 `Ctrl+Shift+M`：把当前剪贴板内容**直接**收进「快速收集」分类，
  托盘弹通知「已收集，点击查看」——不想被打断时的零打扰路径
- 便签输入框内选中的文字 → 右键菜单「存入备忘录」（应用内右键完全可控，
  这是 SnapNote 自己的地盘）

### 3.2 数据模型（直观版）

**分类 = 无限层级的文件夹树**：
「快速收集」为内置默认分类（不可删除，快捷键收集的落点），根级可自建
「账号密码」「工作资料」等大类，每类下再建子类、子子类……

**每条内容记录**：内容本体（文字 / 图片文件路径）+ 所属分类 + 收集时间 +
来源（剪贴板/快捷键/扩展/手动）+ 备注栏（可写账号名等提示）+ 敏感标记。

**图片**：图片本体存独立目录（`用户数据\memo-assets\`），按内容指纹命名
自动去重（同一张图收两遍只存一份）；数据文件里只存路径，体积不失控。

**数据安全边界**：
- 全部数据只存本机（AppData 用户数据目录），无任何上传
- 备忘录数据与任务便签数据**完全隔离**（独立文件），互不影响
- 与任务数据同等的落盘保障（防抖写入 + 备份文件）

### 3.3 备忘录管理界面（新独立窗口）

**打开入口**（沿用 v1.3.0 的三入口一致性）：
- 托盘右键菜单 →「备忘录」
- 便签头部图标按钮
- 快捷键 `Ctrl+Shift+O`

**布局**（约 880×560 独立窗口，尺寸位置自动记忆）：

```
┌────────────────────────────────────────────────┐
│ 🔍 搜索框      [全部|文字|图片]  排序  + 新建   │
├──────────┬─────────────────────────────────────┤
│ 分类树    │  条目卡片（双列瀑布）                │
│ ▼ 快速收集 │  ┌────────┐  ┌────────┐            │
| ▼ 账号密码 │  │卡片预览 │  │卡片预览 │            │
│   ▾ 网站  │  │分类路径 │  │分类路径 │            │
│     论坛  │  │时间·来源│  │🔒敏感遮罩│           │
│ ▸ 工作资料 │  └────────┘  └────────┘            │
│          │  …                                  │
│ + 新建分类 │                                     │
└──────────┴─────────────────────────────────────┘
```

**分类树操作**：新建（任意层级）、重命名、删除（分类下有条目时询问：
连条目一起删 / 移到「快速收集」）、拖拽调序、拖拽移动子树。

**条目卡片**：文字显示 3 行预览，图片显示缩略图；底部是分类路径面包屑 +
时间 + 来源图标。**点击卡片 → 详情面板**：完整内容/大图、编辑备注、
移动分类、一键复制回剪贴板、标记/取消敏感、删除。

**敏感条目**：卡片与列表中显示「••••••」遮罩，点击一次显码（再点遮回）。
防的是背后偷瞄的眼睛，不是加密——见 §6 说明。

**拖拽归类**：条目卡片直接拖到左侧分类上 = 移动分类（不进详情页改）。

**删除保护**：删除弹 5 秒「撤销」气泡，手滑有救。

**搜索**：全文搜文字内容 + 备注栏 + 分类名。

### 3.4 设置页新增「备忘录」区

- 捕获总开关（默认开）
- 捕获灵敏度：标准（800ms 检测）/ 省电（1.5s）——影响复制后气泡出现的延迟
- 默认归档分类（级联选择，归档弹窗的默认选中项）
- 浏览器扩展安装引导（二期上线后出现）

### 3.5 技术要点（工程侧）

- 剪贴板检测：主进程轻量轮询（指纹比对，无新内容零动作），CPU 占用 <0.5%
- 悬浮气泡：无边框置顶小窗（不抢焦点），与 v1.4.0 全屏提醒同技术族
- memo 窗口独立生命周期：关备忘录窗口 ≠ 退应用
- 复用现有基础设施：Store 落盘模式、Tray/IPC/pushState 架构、三入口状态推送
- **测试**：memo 模块（分类树 CRUD/移动/删除语义、去重、敏感遮罩逻辑）
  单测全覆盖；CI 冒烟新增 memo 窗口启动自检

## 四、二期详细设计（v1.6.0 浏览器扩展）

### 4.1 你会看到的体验

网页里选中一段文字 → 右键 → 菜单出现：

```
存入 SnapNote 备忘录            ← 直接入「快速收集」
存入 SnapNote 备忘录到 ▸        ← 展开分类子菜单（大类/子类直达
                                   更深层级走「选择分类…」级联面板）
```

在图片上右键 →「存入图片到 SnapNote 备忘录」（含来源网页地址，方便回溯）。

SnapNote 未运行时点菜单 → 扩展图标提示「SnapNote 未运行」，不丢数据。

### 4.2 架构

- 扩展：Chromium 通用（Chrome/Edge 都能装），manifest v3
- 通信：SnapNote 在本机 `127.0.0.1` 起一个**仅本机可访问**的小服务接收
  扩展推送；首次使用需「配对码」配对（SnapNote 生成，扩展页粘贴），
  防止本机其他程序伪造请求
- 图片：扩展直接抓图发过来（不走剪贴板，不打扰你正在复制的东西）

### 4.3 安装引导（命令行零基础友好）

设置页「浏览器扩展」区一键完成：
1. 自动把扩展文件解压到固定目录
2. 打开图文引导页（Edge/Chrome 一步步截图）：开启开发者模式 →
   加载已解压的扩展 → 选中目录
3. 显示配对码，指引粘贴到扩展弹出页 → 配对完成

不上架商店（开发者模式加载，免审核、免账号、永久可用）。

> 说明：扩展需要「读取你访问的网页」权限才能抓选中的内容和图片——
> 引导页会用一段直白的话解释为什么、以及数据只进本机 SnapNote。

## 五、验收标准（一期）

1. 记事本/浏览器里复制文字 → 气泡出现 → 归档到三级分类 → 管理界面
   该分类下可见、可搜索、可复制回
2. 复制图片（网页右键复制图 / 截图工具复制）→ 同上，缩略图正常
3. `Ctrl+Shift+M` 快速收集 → 托盘通知 + 「快速收集」分类出现该条
4. 分类树：建 4 级层级、重命名、拖拽调序、删除（含条目处理选择）全部正常
5. 敏感条目遮罩/显码正常
6. 任务便签功能、数据完全不受影响；既有 57 项测试全绿 + 新模块测试通过
7. CI 打包产物冒烟含 memo 窗口自检

## 六、需要你知晓的边界（诚实条款）

- **「复制即收集」≠「右键即收集」**：一期在所有软件里靠复制动作触发
  （这是 Windows 系统边界，非偷懒）；你要的真右键在二期网页内实现
- **密码遮罩是防偷瞄，不是加密**：数据文件在本机磁盘上是可被专业工具
  读取的明文（和记事本存密码同级安全）。轻量账号密码没问题，
  核心资产密码建议专业密码管理器
- 扩展权限提示会如实声明用途，无任何数据上传
